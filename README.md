# Gesiele Nails - publicacao

Este repositorio contem somente os arquivos estaticos gerados para o GitHub Pages.

O codigo-fonte, os templates, os dados de fallback, o gerador Python e os arquivos do banco ficam em um repositorio privado. Alteracoes de conteudo feitas pelo painel administrativo sao armazenadas no Supabase.
